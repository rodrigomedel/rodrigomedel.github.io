# Rodrigo M. Medel | Política y sociedad

Sitio estático preparado para GitHub Pages. Conserva las siete páginas, el selector español/inglés, las publicaciones y el diseño aprobado.

## Publicación sin instalar programas

1. Crea un repositorio público llamado TU_USUARIO.github.io, sustituyendo TU_USUARIO por tu nombre de usuario real en GitHub.
2. Descomprime este ZIP en tu computador.
3. En el repositorio, pulsa Add file > Upload files. Sube el contenido de la carpeta descomprimida, incluida la carpeta assets. index.html debe quedar en la raíz del repositorio.
4. Guarda con Commit changes. Si tu computador no muestra .nojekyll, créalo desde Add file > Create new file: nombre .nojekyll, contenido vacío, y guarda.
5. En Settings > Pages, selecciona Deploy from a branch, rama main, carpeta / (root), y pulsa Save.
6. Espera a que GitHub termine la publicación. La dirección será https://TU_USUARIO.github.io/.

Los cambios guardados en la rama main se publican automáticamente. GitHub y la versión de ChatGPT son copias independientes: los cambios en una no se sincronizan automáticamente con la otra.

Los enlaces internos son relativos y también permiten alojar esta copia en un repositorio de proyecto. Cuando conozcas la dirección definitiva podrás añadir las etiquetas canonical y og:url.
